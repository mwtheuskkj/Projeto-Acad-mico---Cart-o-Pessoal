# Mini-Projeto Acadêmico | Card Pessoal

Durante a aula de "Desenvolvimento Front-End Para Web" foi passado um mini-projeto acadêmico onde era preciso criar um card pessoal.
Nesse mini-projeto foi utilizado a linguagem HTML e CSS para o desenvolvimento. HTML onde foi criado a estrutura do site e o CSS para dar vida com um design único. Além das linguagens utilizei alguns meios para personalizar o meu card pessoal utilizando URL de imagens/gifs.

Intuito desse mini-projeto além de desenvolver nossa capacidade em HTML e CSS é para termos noção de como funciona o desenvolvimento front-end, além de uma maneira de linkar nossas redes sociais de uma maneira profissional, onde se destaca o GitHub e LinkedIn.
